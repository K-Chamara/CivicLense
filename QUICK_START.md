## 👤 **For Citizens**

### **See Real Community Support:**
1. Login → Raise Concern
2. Type description (100+ characters)
3. Wait 3 seconds
4. Scroll down
5. ✅ **SEE**: Engagement meter with % and citizen count

**Shows:** How many citizens supported similar concerns (real data from database)

---

## 🧠 **For Anti-Corruption Officers**

### **Access AI Assistant:**
1. Login as officer
2. Concern Management → Click any concern
3. Tap **🧠 brain icon** (top-right)
4. AI Assistant panel opens

### **5 AI Tools Available:**

| Tool | Time | What It Does |
|------|------|--------------|
| 🎯 Risk Assessment | 10s | Shows investigation risks + mitigation |
| 🔍 Evidence Analysis | 10s | Rates evidence quality + collection plan |
| 📋 Investigation Strategy | 15s | Creates phase-by-phase investigation plan |
| 🔄 Check Duplicates | 10s | Finds similar concerns in database |
| ✉️ Response Generator | 10s | Drafts professional citizen response |

### **How to Use:**
1. Tap "Analyze" on any tool
2. Wait 5-15 seconds (AI processing)
3. View results
4. Tap "Copy Report" to copy

## 🔧 **Troubleshooting**

| Problem | Solution |
|---------|----------|
| Engagement shows 0% | Type more (need 20+ chars), wait 3 seconds |
| AI not responding | Check internet, retry after few seconds |
| Brain icon missing | Make sure you're on Concern Detail Screen |
| Analysis failed | Check internet, Gemini API might be temporarily down |

## 💡 **Pro Tips**

1. **For Officers:**
   - Run Risk Assessment FIRST to prepare for challenges
   - Use Evidence Analysis to know what to collect
   - Copy Investigation Strategy and use as checklist
   - Generate Response to save 30 minutes per case

2. **For Citizens:**
   - Write detailed descriptions (AI works better with details)
   - Check engagement meter to see if others have similar issues
   - Use AI category suggestion (it's usually accurate)
